# 吉他譜架

彈吉他時邊彈邊看譜的網頁：<https://agan0617.github.io/GuitarTab/>

- 譜以圖片存在**私有** repo（預設 `agan0617/CloudSave` 的 `saves/guitartab/`），網頁用 fine-grained token 讀取，這個公開 repo 裡沒有任何譜
- 跟 [K書吧](https://github.com/agan0617/KBookBar) 在同一個網域，瀏覽器連過 K書吧就自動沿用那組 token；沒連過就按「連線設定」貼一次
- 譜架照這台裝置最近彈的排序

## 看譜

| 版面 | 什麼時候 | 翻頁 |
|---|---|---|
| 並排 | 橫向寬螢幕（電腦） | 兩頁並排、塞滿螢幕高度；一次翻一頁，看完左頁、右頁移到左邊 |
| 捲動 | 直放（手機、平板） | 一頁接一頁往下捲 |

- 點畫面左側三成翻上一頁、右側三成翻下一頁，中間叫出工具列（幾秒沒動會自動收起）
- 鍵盤與藍牙翻頁踏板：→ ↓ PageDown 空白鍵 Enter 下一頁；← ↑ PageUp 上一頁；A 自動；－／＋ 調速；L 切換版面；F 全螢幕；Esc 回譜架
- **自動**：依譜的速度（♩）、每頁小節數與拍號算出每頁要停多久，並排版面到時間自動翻頁，捲動版面等速往下捲；速度可以用百分比放慢（每首各自記住）
- 看譜時螢幕不會自動關閉
- 看過的譜圖存在瀏覽器快取，再開不用重抓

## 譜的格式

`saves/guitartab/library.json`：

```json
{
  "tabs": [
    {
      "id": "g20261015001000",
      "title": "卡農",
      "artist": "帕海貝爾",
      "tempo": 82,
      "beats": 4,
      "addedAt": "2026-10-15T00:10:00+08:00",
      "updatedAt": "2026-10-15T00:10:00+08:00",
      "pages": [
        { "file": "tabs/g20261015001000/p1.webp", "measures": 23 }
      ]
    }
  ]
}
```

- `pages[].file` 是相對於 `saves/guitartab/` 的路徑；`measures` 是那一頁的小節數，自動翻頁用
- 換了譜圖要更新 `updatedAt`，瀏覽器才會重抓
