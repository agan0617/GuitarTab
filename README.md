# 吉他譜架

彈吉他時邊彈邊看譜的網頁：<https://agan0617.github.io/GuitarTab/>

- 六線譜是 [alphaTex](https://www.alphatab.net/docs/alphatex/introduction) 純文字檔，由 [alphaTab](https://www.alphatab.net/) 畫成六線譜（含和弦名與和弦圖）並播放
- 和弦歌詞譜（只有和弦＋歌詞、沒有 tab 的那種）是 [ChordPro](https://www.chordpro.org/) 純文字檔，和弦顯示在對應的字正上方
- 譜存在**私有** repo（預設 `agan0617/CloudSave` 的 `saves/guitartab/`），網頁用 fine-grained token 讀取，這個公開 repo 裡沒有任何譜
- 跟 [K書吧](https://github.com/agan0617/KBookBar) 在同一個網域，瀏覽器連過 K書吧就自動沿用那組 token；沒連過就按「連線設定」貼一次
- 譜架照這台裝置最近彈的排序；看過的譜存在瀏覽器裡，離線也能開
- Android App 在 [GuitarTabApp](https://github.com/agan0617/GuitarTabApp)（WebView 開這個網頁）

## 看譜

- **播放**：照譜彈出吉他聲，游標照譜上的速度一拍一拍走，譜自動捲到正在彈的地方；點譜上任一小節從那裡開始。停止鍵回到開頭
- **載入音色**：開譜後按鈕顯示「載入音色…」時還不能播，要等音色庫下載完；第一次要有網路
- **聲音**：MIDI 合成的吉他音色，不是錄音，拿來對節奏、對旋律用。關掉（🔇）就只剩游標在走，當作自動捲譜；節拍器可以另外開
- **音量**：🎚 打開音量面板，吉他與節拍器各自 0%～150%；拉滑桿會順便把那一路打開。音量所有譜共用
- **音色**：🎸 選單換吉他音色（尼龍弦、鋼弦、爵士、清音、悶音、破音、失真），播到一半換會從原位置接著播；沒選過就用譜檔的音色（預設鋼弦）
- **速度**：用百分比放慢或加快（30%～150%），練習時從慢的開始
- **譜大小**：A− A＋ 縮放；速度、聲音、節拍器、音色、大小每首各自記住
- 看譜時螢幕不會自動關閉；播放中工具列幾秒後自動收起，點譜面叫出來
- **和弦按法**：譜最上面一排和弦圖可以點，跳出放大的按法圖與每條弦第幾品、建議手指、哪幾條不彈。六線譜用譜檔 `\chord` 的定義；和弦歌詞譜用內建常用和弦表，點歌詞上的和弦名也會跳
- **歌詞**：六線譜的歌詞掛在唱的那一拍上（alphaTex `{lyrics "字"}`，第二段詞 `{lyrics 1 "字"}`），顯示在六線譜上方
- **和弦歌詞譜**沒有聲音：▶ 捲動是照速度自動往下捲，－ ＋ 調捲動速度；A− A＋ 調字級，🎨 換底色

鍵盤與藍牙翻頁踏板：

| 按鍵 | 動作 |
|---|---|
| 空白鍵 | 播放／暫停 |
| → ↓ PageDown Enter | 往下捲一頁 |
| ← ↑ PageUp | 往上捲一頁 |
| Home | 回到開頭 |
| － ＋ | 慢一點／快一點 |
| M／K | 聲音開關／節拍器開關 |
| V | 音量面板 |
| F | 全螢幕 |
| Esc | 回譜架 |

## 譜的格式

`saves/guitartab/library.json`：

```json
{
  "tabs": [
    {
      "id": "g20261015001000",
      "title": "卡農",
      "artist": "帕海貝爾",
      "tempo": 82,
      "bars": 69,
      "file": "tabs/卡農.tex",
      "addedAt": "2026-10-15T00:10:00+08:00",
      "updatedAt": "2026-10-15T00:50:00+08:00"
    }
  ]
}
```

- `file` 是相對於 `saves/guitartab/` 的路徑，內容是 alphaTex；`tempo`、`bars` 只用在譜架上顯示，播放速度以譜檔裡的 `\tempo` 為準
- `tags` 是類型（例 `["華語"]`），譜架上方「類型」那排照它分類；「譜種」那排看 `type` 自動分六線譜／和弦譜。搜尋框找歌名、歌手、來源、類型，空白隔開的詞要全部對到；電腦上按 `/` 跳到搜尋框，只剩一首時按 Enter 直接打開
- 和弦歌詞譜那一筆加 `"type": "chords"`，`file` 指向 `.cho`（ChordPro）
- 改了譜檔要更新 `updatedAt`，瀏覽器才會重抓

### 和弦歌詞譜（ChordPro）

```
{title: 成都}
{artist: 趙雷}
{key: D（彈 C 調）}
{capo: 2}
{tempo: 62}
{c: 前奏}
| C  Am | F  C | C  Am | F  G  C - |
{c: 主歌}
讓我掉[C]下眼淚的　不[Em]止昨夜的酒
{soc}
[C]和我在成都的街頭[Am]走一[F]走
{eoc}
{sot}
e|-----0-----|
{eot}
```

- `[和弦]` 寫在那個字前面；`|` 開頭的行是和弦進行，原樣顯示
- 支援 `{title}` `{subtitle}` `{artist}` `{key}` `{capo}` `{tempo}`、`{c: 說明}`、`{soc}`／`{eoc}`（副歌框）、`{sot}`／`{eot}`（原樣顯示，放六線譜片段）
